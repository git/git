# Organization Profile

## Identity

`AcreetionOS` should be described in this repository as an open community organization, not just a software company and not just an informal code fork.

That framing fits the public material on `acreetionos.org` better:

- independent
- community-focused
- transparent
- sovereignty-oriented
- stability-oriented

## Public Values Relevant To Ace

From the public AcreetionOS site, the values most relevant to this repository are:

- independence from opaque outside control
- transparency in governance and technical direction
- stability over trend-following
- user control over tooling and infrastructure
- repository sovereignty as a real operational principle

## What That Means In Practice For Ace

- Ace should stay Git-native rather than introducing unnecessary hidden infrastructure.
- Documentation should be candid about what is stable, experimental, inherited, and custom.
- Features should improve user and operator control rather than abstracting important behavior away.
- Integrations should support open workflows and avoid making one hosted platform the assumed center of the product.

## Short Positioning Statement

Ace is the Git-native workflow platform developed under AcreetionOS: an open community organization focused on sovereignty, stability, transparency, and practical control.
